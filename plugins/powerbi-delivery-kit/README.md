# powerbi-delivery-kit

Power BI delivery: shared design + data → state.json → HTML mockup, Power BI report (TMDL model + PBIR pages) and interactive HTML twin. Includes the vendored Microsoft powerbi-authoring skills and the Power BI Modeling MCP.

> GENERATED by tools/build-plugin.js — edit .claude/ instead. Built from version 0.2.0.

## Install

```
/plugin marketplace add <clone path or git URL of the kit repo>
/plugin install powerbi-delivery-kit@powerbi-kit
```
Restart Claude Code, then run `/setup` once on each computer.

## Contents

- Skills: `pbi-delivery` (method + scripts), `semantic-model-authoring` and `powerbi-report-cli` (vendored, see `common/VENDORED.md`).
- Commands: `/build-html` · `/build-mockup` · `/build-pbi` · `/dashboard` · `/new-project` · `/setup` · `/status`.
- Agent: `model-reviewer`.
- MCP: `powerbi-modeling-mcp` (via `npx`; accept its EULA once).

## Requirements

Node.js 20+, Power BI Desktop, Git, `npm install -g @microsoft/powerbi-report-authoring-cli@latest`.
